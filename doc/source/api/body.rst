Body
====

Describe a collection of particles with a single primary type and any number of
secondary types. :class:`~p4.Body` is a declarative wrapper around
`hoomd.md.constrain.Rigid <https://hoomd-blue.readthedocs.io/en/latest/hoomd/md/constrain/rigid.html>`_.
