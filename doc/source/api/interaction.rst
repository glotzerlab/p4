.. _interaction:

Interaction
===========

Describe a pairwise interaction with a HOOMD-blue class and the data needed to
instantiate and parameterize that class. :class:`~p4.Interaction` is a declarative
wrapper around instantiable subclasses of `hoomd.md.pair.Pair <https://hoomd-blue.readthedocs.io/en/latest/hoomd/md/pair/pair.html>`_.
